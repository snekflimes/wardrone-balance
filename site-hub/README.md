# Главная snek.su — хаб проектов

Содержимое этой папки залейте в **корень сайта** на Reg.ru (туда же, где должен открываться `https://snek.su/`):

- `index.html` — публичная страница со ссылками
- `data/projects.json` — список проектов (можно править вручную или через админку)
- `admin/` — PHP-сохранение и веб-редактор

Подпапки вроде `/wardrone/` не трогайте: они остаются как есть.

## Настройка админки

1. Скопируйте `admin/config.example.php` → `admin/config.local.php`.
2. Задайте длинный случайный `adminToken` (не коммитьте `config.local.php`).
3. Убедитесь, что PHP может писать в `data/` (права 755 на папку, 644 на файл после первой записи).

Откройте `https://snek.su/admin/` (или ваш путь), вставьте токен → **Загрузить** → правки → **Сохранить на сервер**.

## Если «сайт размещён некорректно»

В панели Reg.ru корень домена должен указывать на каталог, где лежит этот `index.html`. Если корень смотрит в пустую папку или только в `/wardrone/`, главная не откроется — переназначьте document root или положите копию хаба в нужный каталог.
